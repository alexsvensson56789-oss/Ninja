# Nine Peaks: Clan of the Lantern

An original browser ninja clan battler. Found a clan, recruit ninjas, arm them, and fight
through a five-chapter story to recover the stolen Lantern of Dawn.

Open `index.html` in any modern browser — no build step or server needed. Progress saves
in the browser's local storage.

- **Story** – 20 battles across 5 chapters, each ending in a boss
- **Skirmish** – repeatable fights against random rival clans
- **Clan** – roster, stats and weapon loadouts
- **Forge** – 16 weapons unlocked by clan level
- **Tavern** – recruit ninjas with different elements and traits
- **Dojo** – paid training and stamina refills
- **Shrine** – clan-wide relics bought with jade
